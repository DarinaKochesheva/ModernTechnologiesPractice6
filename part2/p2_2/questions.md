# Вопросы по JDBC - Часть 2

## Вопрос 1: LIKE с %

**Вопрос:** Почему используется LIKE с % в `findByTitle`?

**Ваш ответ:**


- % — это wildcard в SQL. 
- %текст% означает «содержит "текст" в любом месте строки». 
Используется для поиска подстроки в названии фильма, а не только точного совпадения.

## Вопрос 2: PreparedStatement vs Statement

**Вопрос:** Что такое PreparedStatement и почему он безопаснее Statement?

**Ваш ответ:**

PreparedStatement — это способ выполнения SQL-запросов, при котором запрос пишется один раз с плейсхолдерами ?, а значения подставляются отдельно.

Он безопаснее Statement, потому что отделяет код SQL от данных. При использовании Statement данные склеиваются со строкой запроса, и злоумышленник может передать значение, которое изменит логику запроса (например, ' OR '1'='1). PreparedStatement автоматически экранирует специальные символы и передает значения как данные, поэтому такой трюк не сработает.
