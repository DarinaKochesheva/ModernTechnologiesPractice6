# Вопросы по JDBC - Часть 2

## Вопрос 1: LIKE с %

**Вопрос:** Почему используется LIKE с % в `findByTitle`?

**Ваш ответ:**


- % — это wildcard в SQL. 
- %текст% означает «содержит "текст" в любом месте строки». 
Используется для поиска подстроки в названии фильма, а не только точного совпадения.

## Вопрос 2: PreparedStatement vs Statement

**Вопрос:** Что такое PreparedStatement и почему он безопаснее Statement?

**Ваш ответ:**

PreparedStatement — это способ выполнения SQL-запросов, при котором запрос пишется один раз с плейсхолдерами ?, а значения подставляются отдельно.

Он безопаснее Statement, потому что отделяет код SQL от данных. При использовании Statement данные склеиваются со строкой запроса, и злоумышленник может передать значение, которое изменит логику запроса (например, ' OR '1'='1). PreparedStatement автоматически экранирует специальные символы и передает значения как данные, поэтому такой трюк не сработает.

### Ответ 1:
`%` - это wildcard символ в SQL LIKE:
- `%текст` - заканчивается на "текст"
- `текст%` - начинается на "текст"
- `%текст%` - содержит "текст" в любом месте

Используем `%текст%` для поиска подстроки в названии фильма.

### Ответ 2:
**PreparedStatement:**
- Предварительно компилирует SQL запрос
- Использует параметры (?) вместо конкатенации строк
- Защищает от SQL Injection
- Может повторно использоваться с разными параметрами
- Лучшая производительность при многократном выполнении

**SQL Injection пример:**
```java
// Опасно с Statement:
String input = "' OR '1'='1";
stmt.execute("SELECT * FROM users WHERE name = '" + input + "'");
// Выполнится: SELECT * FROM users WHERE name = '' OR '1'='1'
// Вернет все записи!

// Безопасно с PreparedStatement:
pstmt = conn.prepareStatement("SELECT * FROM users WHERE name = ?");
pstmt.setString(1, input);
// Ищет пользователя с именем "' OR '1'='1" (которого нет)
```
